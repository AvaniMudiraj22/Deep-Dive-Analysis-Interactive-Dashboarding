# Deep-Dive Analysis & Interactive Dashboarding

## Overview
An interactive business analytics dashboard built using Python, Pandas, Plotly, and Dash. This project performs customer cohort analysis, retention tracking, KPI analysis, and data visualization using transactional data.

## Features
- Cohort Analysis
- Retention Heatmap
- KPI Dashboard
- Interactive Visualizations

## Technologies Used
- Python
- Pandas
- NumPy
- Plotly
- Dash
